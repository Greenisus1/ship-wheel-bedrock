# Ship Wheel (Bedrock add-on)

Placeable ship wheel block with script-based block-step driving for Minecraft Bedrock. MIT licensed.

Status: only checked with JSON validation, a JS syntax check and a mock API run. Not tested in real Bedrock yet. Uses @minecraft/server 2.8.0. No rotation, steered by look direction.

AI note: this add-on was written with the help of an AI assistant and published by Greenisus1 (WinnieGaming).
